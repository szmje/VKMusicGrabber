# VKMusicGrabber 🎵

Надежный и производительный инструмент для скачивания музыки из ВКонтакте (`vk.ru` и `vk.com`) с автоматическим встраиванием ID3-тегов, обложек, поддержкой HLS AES-128 стриминга и умным архивом загрузок.

Готов к работе как в виде автономного `.exe` файла (без установки Python), так и в виде исходного Python-скрипта.

---

## ⚡ Особенности

- 🔒 **Авторизация на выбор:**
  - По логину и паролю (с поддержкой 2FA двухфакторной аутентификации).
  - Через Access Token (Kate Mobile / vkhost).
  - Через Cookies браузера (`remixsid`).
  - Сохранение сессии в зашифрованном/локальном виде без необходимости повторного ввода.
- 🌐 **Двойная поддержка доменов:**
  - Полная поддержка нового домена `vk.ru` и классического `vk.com` (автоматическая маршрутизация ссылок).
- 🎧 **HLS AES-128 & MPEG-TS Decryption:**
  - Автоматическая загрузка зашифрованных HLS `.m3u8` плейлистов ВКонтакте.
  - Дешифрование фрагментов AES-128 на лету.
  - Встроенный чистый Python MPEG-TS аудиодемультиплексор (работает «из коробки» без внешних утилит).
  - Поддержка быстрого копирования через FFmpeg при его наличии в системе.
- 🏷️ **ID3-теги и обложки альбомов:**
  - Автоматическая запись метаданных: исполнитель, название, альбом.
  - Загрузка и вшивание оригинальных обложек максимального разрешения.
- 📦 **Умный архив (`archive.txt`):**
  - Запоминает ID уже загруженных треков и пропускает их при повторных запусках.
- 🛡️ **Анти-бан и защита от лимитов:**
  - Рандомизированные задержки между запросами (настраиваемые через CLI).
  - Exponential backoff с автоматическим повтором при сбоях сети или ошибках VK API.
  - Автоматическая валидация размера аудио (файлы-пустышки отбраковываются).
- 🎯 **Гибкие источники:**
  - Аудиозаписи пользователя (`--user-id`).
  - Плейлисты и альбомы (`--playlist`).
  - Поиск по каталогу музыки (`--search`).

## 🚀 Быстрый старт (Готовый .EXE)

Скачайте готовый `VKMusicGrabber.exe` со страницы [**Releases**](../../releases/latest).

Запуск в интерактивном режиме (двойной клик или через консоль):
```powershell
VKMusicGrabber.exe
```

Скрипт запросит необходимые параметры прямо в терминале с удобным текстовым интерфейсом.

## 💻 Использование через командную строку (CLI)

```text
Использование: VKMusicGrabber.exe [параметры]

Опции:
  -h, --help            Показать справку
  -d, --domain          Основной домен VK (vk.ru или vk.com, по умолчанию: vk.ru)
  -l, --login           Логин VK (телефон или e-mail)
  -p, --password        Пароль VK
  -t, --token           Access Token VK
  -c, --cookies         Куки remixsid
  -o, --output          Папка для сохранения музыки (по умолчанию: ./downloads)
  -u, --user-id         ID или короткое имя пользователя (например, durov, id12345)
  --playlist            Ссылка на плейлист (например, https://vk.ru/music/playlist/-123_456_key)
  -s, --search          Поисковый запрос
  --count               Количество треков для скачивания (по умолчанию: 100)
  --min-delay           Мин. задержка между треками (сек., default: 2.0)
  --max-delay           Макс. задержка между треками (сек., default: 4.5)
```

### Примеры:

**Скачать аудиозаписи пользователя по токену:**
```powershell
VKMusicGrabber.exe -t "vk1.a.xxxx..." -u "durov" -o "D:\Music"
```

**Скачать плейлист:**
```powershell
VKMusicGrabber.exe -t "vk1.a.xxxx..." --playlist "https://vk.ru/music/playlist/12345_678_hash"
```

**Поиск и скачивание:**
```powershell
VKMusicGrabber.exe -t "vk1.a.xxxx..." -s "Linkin Park" --count 20
```

## 🛠️ Запуск из исходного кода

### 1. Требования
- Python 3.10+
- (Опционально) FFmpeg в системном `PATH` для ускорения демультиплексирования.

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск
```bash
python vk_audio_downloader.py
```

### 4. Тестирование
```bash
pytest -v
```

### 5. Самостоятельная сборка в .exe (PyInstaller)
```bash
pyinstaller --clean VKMusicGrabber.spec
```
Исполняемый файл будет помещен в папку `dist/VKMusicGrabber.exe`.
