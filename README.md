# vkmusicgrabber

консольная утилита для скачивания музыки из вконтакте (vk.ru и vk.com). расшифровывает hls aes-128 потоки, достает аудио в mp3 320 kbps, прописывает id3v2-теги с обложками и ведет архив загрузок, исключая повторные скачивания.

собирается в один .exe через pyinstaller, работает без установленного python.

---

## что умеет

- авторизация через vk oauth (vk.com) по токену или ссылке из адресной строки.
- сессия сохраняется локально в `.vk_session.json`, повторно вводить токен не нужно.
- нет ограничения в 5000 треков: поддерживается постраничная загрузка всей медиатеки любого объема (10к+ треков).
- умный архив загрузок: совместим с форматом yt-dlp ('vk <id>' в archive.txt), поддерживает флаг --download-archive, а также сканирует папку и индексирует уже существующие на диске mp3-файлы, исключая повторные скачивания.
- поддержка ссылок как с нового `vk.ru`, так и с `vk.com`.
- дешифрование hls aes-128 потоков на лету (`cryptography`).
- встроенный pure-python ts-демультиплексор (работает без сторонних утилит, но если в path есть ffmpeg, использует его).
- теги (артист, название, альбом) и вшивание обложки в максимальном качестве (`mutagen`).
- фильтрация битых файлов: если аудио меньше 100 кб (например, отдали пустой манифест), файл отбраковывается и в архив не пишется.
- продвинутая анти-бан защита: рандомизированные паузы между треками (3.0-6.0 сек), микро-паузы между hls-сегментами, безопасные интервалы при пагинации, периодический отдых каждые 15 треков и автоперехват flood control (ошибки 6/9/29) с паузой и повтором.
- ультра-безопасный режим `--safe` для максимальной защиты аккаунта.
- скачивание из профилей (`-u`), плейлистов (`--playlist`) или через поиск (`-s`).

## готовый бинарник

готовый `vkmusicgrabber.exe` лежит в [релизах](../../releases/latest).

запуск интерактивного мастера:
```powershell
.\vkmusicgrabber.exe
```

при первом запуске скрипт покажет простую инструкцию:
1. открыть в браузере сайт `https://vkhost.github.io`
2. выбрать в списке `vk.com` и нажать "разрешить"
3. скопировать итоговую ссылку из адресной строки браузера и вставить в консоль.

## аргументы cli

```text
использование: vkmusicgrabber.exe [параметры]

опции:
  -h, --help            справка
  -d, --domain          домен (vk.ru или vk.com, по дефолту vk.ru)
  -t, --token           access token vk или ссылка из vkhost (vk.com)
  -o, --output          папка для сохранения (по дефолту ./downloads)
  --download-archive    файл архива в формате yt-dlp (по дефолту archive.txt в папке сохранения)
  -u, --user-id         id/короткое имя пользователя или ссылка на профиль
  --playlist            ссылка или id плейлиста
  -s, --search          поисковый запрос
  --count               число треков (0 = все доступные без ограничений, по дефолту 0)
  --min-delay           минимальная пауза между треками (сек., по дефолту 3.0)
  --max-delay           максимальная пауза между треками (сек., по дефолту 6.0)
  --batch-size          число треков перед паузой отдыха (по дефолту 15)
  --batch-pause         длительность паузы отдыха (сек., по дефолту 25.0)
  --segment-delay       микро-пауза между hls-сегментами (сек., по дефолту 0.08)
  --safe                ультра-безопасный режим для защиты от блокировок
```

примеры:

скачать все треки со страницы без ограничений:
```powershell
.\vkmusicgrabber.exe -t "vk1.a..." -u "durov" -o "d:\music"
```

скачать весь плейлист целиком:
```powershell
.\vkmusicgrabber.exe -t "vk1.a..." --playlist "https://vk.ru/music/playlist/12345_678_hash"
```

скачать первые 20 треков из поиска:
```powershell
.\vkmusicgrabber.exe -t "vk1.a..." -s "sonic death" --count 20
```

## запуск из исходников

нужен python 3.10+. ffmpeg опционален.

установка зависимостей:
```bash
pip install -r requirements.txt
```

запуск скрипта:
```bash
python vk_audio_downloader.py
```

прогон тестов:
```bash
pytest -v
```

сборка в exe:
```bash
pyinstaller --clean vkmusicgrabber.spec
```
бинарник появится в `dist/vkmusicgrabber.exe`.
