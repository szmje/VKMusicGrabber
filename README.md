# vkmusicgrabber

консольная утилита для скачивания музыки из вконтакте (vk.ru и vk.com). расшифровывает hls aes-128 потоки, достает аудио в mp3 320 kbps, прописывает id3v2-теги с обложками и ведет архив загрузок, чтобы не качать одно и то же по кругу.

собирается в один .exe через pyinstaller, работает без установленного python.

---

## что умеет

- вход по логину/паролю (с поддержкой 2fa), через токен kate mobile / vkhost или по кукам `remixsid`.
- сессия сохраняется локально в `.vk_session.json`, повторно логиниться не нужно.
- поддержка ссылок как с нового `vk.ru`, так и со старого `vk.com`.
- дешифрование hls aes-128 потоков на лету (`cryptography`).
- встроенный pure-python ts-демультиплексор (работает без сторонних утилит, но если в path есть ffmpeg, использует его).
- теги (артист, название, альбом) и вшивание обложки в максимальном качестве (`mutagen`).
- фильтрация битых треков: если аудио меньше 100 кб (например, отдали пустой манифест), файл отбраковывается и в архив не пишется.
- `archive.txt` с id скачанных треков для пропуска дубликатов при следующих запусках.
- рандомные паузы между запросами и ретраи при сбоях сети.
- скачивание из профилей (`-u`), плейлистов (`--playlist`) или через поиск (`-s`).

## готовый бинарник

готовый `vkmusicgrabber.exe` лежит в [релизах](../../releases/latest).

запуск интерактивного мастера (спросит все нужные данные сам):
```powershell
.\vkmusicgrabber.exe
```

## аргументы cli

```text
использование: vkmusicgrabber.exe [параметры]

опции:
  -h, --help            справка
  -d, --domain          домен (vk.ru или vk.com, по дефолту vk.ru)
  -l, --login           логин (телефон или почта)
  -p, --password        пароль
  -t, --token           access token
  -c, --cookies         куки remixsid
  -o, --output          папка для сохранения (по дефолту ./downloads)
  -u, --user-id         id/короткое имя пользователя или ссылка на профиль
  --playlist            ссылка или id плейлиста
  -s, --search          поисковый запрос
  --count               число треков (по дефолту 100)
  --min-delay           минимальная пауза между треками (сек., по дефолту 2.0)
  --max-delay           максимальная пауза между треками (сек., по дефолту 4.5)
```

примеры:

скачать аудиозаписи со страницы:
```powershell
.\vkmusicgrabber.exe -t "vk1.a..." -u "durov" -o "d:\music"
```

скачать плейлист:
```powershell
.\vkmusicgrabber.exe -t "vk1.a..." --playlist "https://vk.ru/music/playlist/12345_678_hash"
```

скачать из поиска:
```powershell
.\vkmusicgrabber.exe -t "vk1.a..." -s "sonic death" --count 20
```

## запуск из исходников

нужен python 3.10+. ffmpeg опционален.

установка зависимостей:
```bash
pip install -r requirements.txt
```

запуск скрипта:
```bash
python vk_audio_downloader.py
```

прогон тестов:
```bash
pytest -v
```

сборка в exe:
```bash
pyinstaller --clean vkmusicgrabber.spec
```
бинарник появится в `dist/vkmusicgrabber.exe`.
